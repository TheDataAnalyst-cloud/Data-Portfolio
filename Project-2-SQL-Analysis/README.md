# Project 2: SQL Sales Analysis

## 📌 Overview
This project analyzes e-commerce sales data using MySQL to extract business insights from a dataset of **150 orders**.  
The goal was to practice SQL skills and uncover actionable business insights.

## 🛠️ Tools Used
- **MySQL Workbench**
- SQL (Aggregations, GROUP BY, ORDER BY, Subqueries, Date Functions)

## 📊 Data Source
- **Superstore dataset** (150-row sample)
- Columns: Category, Region, Segment, Sales, Order Date, Customer Name, etc.

---

## 🔍 Key Insights (Based on 150 Orders)

| # | Insight |
|---|---------|
| 1 | **Total Sales:** $30,766 across 72 orders |
| 2 | **Average Order Value:** $427.31 |
| 3 | **Top Category:** Furniture ($15,773) — 51% of total sales |
| 4 | **Top Region:** West ($10,229) — Central is close ($10,048) |
| 5 | **Top Segment:** Consumer ($19,388) — 63% of total sales |
| 6 | **Top Customer:** Brosin Hoffman ($3,714) |
| 7 | **Top Product:** Riverside Palais Royal Lawyers Bookcase ($3,083) |
| 8 | **Primary Ship Mode:** Standard Class ($23,846) — 77% of orders |
| 9 | **Best Month:** May 2017 ($3,135) |
| 10 | **Furniture dominates the West region** ($4,133) |
